# PC Follow v0.1.13

PT外を含むPCを開始時にターゲットしてロックし、その後は追従相手をターゲットし続けなくても追従するDalamudプラグインです。

## 追従方式

### 1. 標準Follow型
- FF14標準の `/follow` を使用
- 戦闘や操作でFollowが切れたら、ロックしたPCへ自動で掛け直す
- 掛け直し時だけ一時ターゲットし、その後は元の戦闘ターゲットへ戻す
- エリア移動後も対象名を保持し、再出現後に同じPCへ自動復帰

### 2. VNA型追従
- vnavmesh必須
- AutoFollowを参考に、毎フレーム経路再計算しない
- 初期値は1秒間隔で確認し、相手が5m以上移動した時だけ経路更新
- 5m以内で停止、7m以上で再追従
- 対象消失時は最後に確認した位置まで移動して待機
- エリア移動後は同じPCの再出現を待って追従再開

## HP低下時スキル
- 追従相手のHPが前回より減少
- かつ設定したHP%以下
- 指定スキルを追従相手へ使用
- 実行時のみ一時ターゲットし、元ターゲットへ戻す

## 操作
- `/pcfollow` 設定画面
- `/pcfollow start` 現在ターゲット中のPCをロックして追従開始
- `/pcfollow stop` 追従停止

## ローカル配置
`build.bat` 成功後: `Z:\PCFollow\Current\`

## v0.1.10 回復とRSR連携
追従相手のHPが設定値以下まで減った場合、PC Followが回復要求を保持します。Rotation Solver RebornがAuto中なら一時停止し、現在の詠唱が終わってから指定した回復スキルを追従相手へ使用します。処理後は、元々Autoだった場合だけRSRをAutoへ戻します。追従相手を手動ターゲットし続ける必要はありません。

## v0.1.11 RSR停止後の待機強化
回復要求時はRSRへOffを送るだけでなく、IPCでAuto OFFを確認後、予約済み攻撃が抜ける待機時間を設けます。さらに非詠唱状態が250ms連続したことを確認してから、設定した回復スキルを追従対象へ使用します。

## v0.1.12 賢者バリアモード
- 通常モードとは別に「賢者バリアモード」を追加。
- HPは判定に使用しません。追従対象の ShieldPercentage が1%でも低下した時点でRSRを停止し、次の行動をエウクラシア・ディアグノシスへ優先します。
- 通常Diagnosisへ変化している間は実行せず、AdjustedActionIdがEukrasian Diagnosisであることを確認してから使用します。
- バリア増加を確認した後、元々Autoだった場合だけRSRをAutoへ戻します。

## v0.1.13 賢者バリアのリキャスト先読み
- 賢者バリアモードでエウクラシアとエウクラシア・ディアグノシスのリキャスト/GCDを先に判定します。
- バリア低下時はRSRを即停止し、リキャスト中は待機、使用可能になった最初のタイミングでバリアを投入します。
- リキャスト中の無駄なUseAction連打を行いません。
- 状態欄に「エウクラシア待ち x.xx秒」「GCD待ち x.xx秒」を表示します。
